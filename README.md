# InventoryPro – Smart Inventory Management System

InventoryPro is a professional Python-based desktop application designed to simplify and streamline inventory management operations. It provides an intuitive graphical user interface with a premium blue-and-black dashboard, secure authentication, and role-based access for administrators and staff.

The system enables users to manage products, monitor stock levels, maintain supplier information, record stock transactions, and generate inventory reports efficiently.

## Key Features

- Secure Login and Staff Registration
- Admin and Staff Role-Based Access
- Interactive Inventory Dashboard
- Product Management (Add, Edit, Search, Delete)
- Supplier Management
- Stock-In and Stock-Out Tracking
- Low-Stock Monitoring
- Inventory Valuation
- Stock Movement History
- CSV Report Export
- SQLite Database Integration
- Password Hashing and Input Validation

## Technologies Used

- Python
- Tkinter / ttk
- SQLite
- Hashlib
- CSV

## Project Objective

The primary objective of InventoryPro is to provide a simple, efficient, and user-friendly inventory management solution while demonstrating practical applications of Python programming, GUI development, database management, authentication, and software engineering concepts.
